## Expansion host baseline

All 18 unconfigured target hosts were probed before this change. Each returned HTTP 200 with the Melbourne homepage canonical. They were not matching suburb pages. The new request guard makes unconfigured wildcard hosts return not-found, avoiding accidental duplicate location pages. No configured host was removed.

## Rechecking

Run npm run seo:locations for the full machine-readable inventory. The optional --live-expansion flag performs read-only probes of expansion URLs, including response status and canonical. It does not publish, update Google profiles or change indexing gates.

Council and retailer sources support local property guidance, not business occupancy, hours, work history or qualifications. Epping and Narre Warren remain incomplete recorded visitor addresses.
